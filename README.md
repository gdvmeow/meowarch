# Виктория Терзян — архитектурное портфолио

Локальный сайт на React и Vite. Главная страница показывает авторский чертёж и две избранные работы; каталог, страница каждой работы, информация об архитекторе и контакты доступны отдельно. Навигация использует URL-параметры, поэтому ссылки на проекты открываются напрямую и работают с историей браузера.

## Запуск

```bash
npm install
npm run dev
```

Проверка production-сборки: `npm run build`. Готовые файлы находятся в `dist/`.

## GitHub Pages

Проект готов к размещению в новом репозитории GitHub Pages. `vite.config.js` задаёт относительный базовый путь, поэтому имя репозитория не нужно вписывать в код: сборка работает и по адресу `https://USERNAME.github.io/REPOSITORY/`, и в корне сайта с собственным доменом. Страницы и проекты используют URL-параметры (`?page=...`, `?project=...`), поэтому прямые ссылки открываются без серверной маршрутизации.

1. Создайте на GitHub пустой репозиторий. Для бесплатного GitHub Pages он должен быть публичным. Основная ветка — `main`.
2. Загрузите исходники в репозиторий. Папки `node_modules/`, `dist/` и `backups/` исключены через `.gitignore`; загружать их не нужно.
3. В репозитории откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
4. При отправке изменений в `main` файл `.github/workflows/deploy-pages.yml` выполнит `npm ci`, соберёт сайт и опубликует содержимое `dist/`. Запуск вручную доступен на вкладке **Actions**.

После завершения первого запуска адрес появится в **Settings → Pages**. Локально production-версию можно проверить командой `npm run preview`.
Если первый запуск начался до включения GitHub Pages, запустите workflow вручную после выбора **GitHub Actions**.

## Редактирование

Проекты, описания, галереи и внешние ссылки находятся в `src/data.js`. Переводы интерфейса и проектов — в `src/i18n.js`. Изображения сайта лежат в `public/assets/`; стили — в `src/styles.css`. В `src/App.jsx` находятся страницы, навигация, фильтры каталога и просмотр изображений. Шрифты Golos Text и Literata поставляются локально через Fontsource. Визуальные правила собраны в `DESIGN_SYSTEM.md`.

Авторский чертёж `site-background-perspective.png` служит фоном страниц и показан в проекте «Городской фрагмент». На странице «О себе» он используется только как фон. Изображение футера загружается из `footer-architect-drawing.webp`. Предыдущие варианты сохранены в `backups/`.

Перед публикацией замените демонстрационные изображения и описания проектов в `src/data.js` материалами архитектора. Настоящие имя, контакты и авторский фоновый чертёж уже подключены.
